Why this exists

DR tests often recover a VM that nobody can prove is actually serving traffic. Beacon is a tiny public dummy: clone it, run one script, open a browser. If the beam is on, HTTP is working.

  • One Python file. No packages to install.
  • `/health` for load balancers, `/api/status` for JSON evidence.
  • Works as a systemd service on a Linux dummy VM.
  • Safe to share. There is nothing confidential on this page.
